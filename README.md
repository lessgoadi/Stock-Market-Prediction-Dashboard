# 📊 Stock Market Analysis Dashboard (Tableau)

## Project Overview

This project focuses on analyzing and comparing the stock market performance of four major technology companies: Apple, Microsoft, Google, and Netflix.
Using historical stock price data, an interactive dashboard was built in Tableau to visualize trends, trading activity, and price movements.

The goal of this project is to better understand how stock prices change over time and identify patterns such as volatility, trading volume, and relationships between price and market activity.


## Tools Used

* Tableau Desktop
* Microsoft Excel / CSV dataset
* GitHub (for project hosting)


## Dataset

The dataset contains historical stock market data for the following companies:

* Apple (AAPL)
* Microsoft (MSFT)
* Google (GOOG)
* Netflix (NFLX)

Key attributes in the dataset include:

* Date
* Open Price
* High Price
* Low Price
* Close Price
* Adjusted Close Price
* Trading Volume


## Dashboard Features

The Tableau dashboard includes multiple visualizations to explore the stock market data:

### 1. Stock Price Trend

A line chart showing how the closing price of each company changes over time.

### 2. Average Stock Price Comparison

A bar chart comparing the average closing price of the four companies.

### 3. Trading Volume Analysis

A visualization showing daily trading volume for each stock.

### 4. Stock Price Volatility

Displays the difference between daily high and low prices to understand market volatility.

### 5. Moving Average Trend

A moving average calculation was used to smooth out price fluctuations and highlight long-term trends.

### 6. Volume vs Price Scatter Plot

A scatter plot analyzing the relationship between trading volume and stock price.

## Key Insights

* Technology stocks show clear trends over time.
* Some companies experience higher volatility than others.
* Trading volume and price movements can sometimes show correlation.
